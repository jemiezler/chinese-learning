# 中文学习

An Obsidian knowledge base for learning Chinese characters, vocabulary, topics, and grammar.

## Learning system

```text
汉字 → 词汇 → 相关汉字 → 相关词汇
```

## Repository structure

- `00 首页` — home page and learning-system overview
- `01 汉字` — Chinese character notes and index
- `02 词汇` — vocabulary notes and indexes
- `03 主题` — vocabulary organized by topic
- `04 语法` — grammar notes and indexes
- `05 例句` — example sentences
- `99 模板` — templates for characters, vocabulary, and grammar

## Usage

Open this folder as an Obsidian vault. Notes use Obsidian wiki links, properties, and Dataview queries to connect related learning material.
