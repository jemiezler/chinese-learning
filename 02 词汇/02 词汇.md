# 词汇

> Chinese Vocabulary Index

## Vocabulary

```dataview
TABLE WITHOUT ID
    file.link AS "词汇",
    pinyin AS "Pinyin",
    meaning AS "Meaning",
    status AS "Status"
FROM "中文/02 词汇"
WHERE type = "词汇"
SORT pinyin ASC
```
## Vocabulary Families by Character

```dataview
LIST rows.file.link
FROM "中文/02 词汇"
WHERE type = "词汇"
FLATTEN characters AS character
GROUP BY character
SORT character ASC
```
