# 词汇

> Chinese Vocabulary Index

## Vocabulary

```dataview
TABLE WITHOUT ID
    file.link AS "词汇",
    pinyin AS "Pinyin",
    meaning AS "Meaning",
    status AS "Status"
FROM "中文/02 词汇"
WHERE type = "词汇"
SORT pinyin ASC
```
## Vocabulary Families

### 爱 Family

```dataview
TABLE WITHOUT ID
    file.link AS "词汇",
    pinyin AS "Pinyin",
    meaning AS "Meaning"
FROM "中文/02 词汇"
WHERE type = "词汇"
AND contains(characters, [[爱]])
```
