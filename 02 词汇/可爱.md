# 可爱

## Basic information

**Pinyin:** kě'ài  
**English:** cute; adorable; lovable  
**Thai:** น่ารัก

## Character breakdown

[[可]] — kě — can; may; possible  
[[爱]] — ài — love; to love

**可 + 爱 → 可爱**

## Meaning

可爱 means **cute, adorable, or lovable**.

It is commonly used to describe people, animals, appearances, behaviors, or things that make you feel affection toward them.

## Example sentence

**这只猫很可爱。**

**Pinyin:** Zhè zhī māo hěn kě'ài.  
**English:** This cat is very cute.  
**Thai:** แมวตัวนี้น่ารักมาก
